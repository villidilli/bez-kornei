# БЕЗ КОРНЕЙ — передача проекта на новый компьютер

Снимок: 12 ноября 2026. Подготовлен без публикации, изменения DNS, установки WordPress и изменения исходного сайта. Все адаптации путей сделаны только в копии для переноса.

## С чего продолжать

Главная рабочая версия: `bez-korney-preview/index.html`. Это новая цельная страница из согласованных эскизов. Старый публичный сайт https://bez-korney-studio.cherishedfrog1.chatgpt.site/ и его `/works` отличаются от неё. Не заменять новую страницу старой копией из `bez-korney` или `archive`.

Последняя незавершённая задача: пользователь не видит заставку перед страницей. Исправление не завершено. В новой странице заставка есть, но `assembly.js` полностью пропускает её при `prefers-reduced-motion: reduce`. Кроме того, пользователь открывал старый публичный `/works`, а новая анимация была подключена только локально. Нужно воспроизвести обе ситуации, проверить старт и время GIF, кэш и переход к странице. Не объявлять дефект решённым только по наличию GIF. Не добавлять кнопку «Пропустить» и длинную финальную паузу.

## Архитектура и сборка

Сайт статический: HTML/CSS/обычный JavaScript. React, TypeScript, Vite, Next.js, API-сервер, база данных и обязательный npm build в найденных исходниках отсутствуют. До переноса package.json/lock-файлов у сайта не было. Добавленный package.json относится только к необязательным инструментам графики.

Сборщик объединяет фрагменты, извлекает встроенные base64 PNG/JPEG/SVG в `assets/` с именами по хешу и заменяет прежнюю ссылку работ на якорь внутри страницы. `assembly.css` и `assembly.js` редактируются отдельно и не генерируются сборщиком. Не править только собранный index.html: следующая сборка перезапишет его.

Порядок блоков и их исходники:

1. `bez-lounge-hero.html` — первый экран.
2. `bez-why-artificial.html` — преимущества и естественный вид.
3. `bez-selected-works.html` — реальные работы и галереи.
4. `bez-design-partners.html` — дизайнеры и архитекторы.
5. `bez-process.html` — процесс.
6. `bez-cost-factors.html` — стоимость, скрытый пример, бюджет.
7. `bez-questions.html` — вопросы.
8. `bez-contacts.html` — контакты и реквизиты.

Стили и скрипты фрагментов привязаны к своим блокам. Из-за итераций в них есть последовательные CSS-переопределения; перед чисткой сверять итоговый вид. Интерактивность: native details, диалоги галерей, раскрытие контактов, IntersectionObserver, морфинг кнопок. Внешняя аналитика отсутствует, события пока только в локальном `window.dataLayer`.

## Запуск на новом Windows

Распаковать ZIP целиком в постоянную папку, например `C:\Projects\BEZ-KORNEI`. Не запускать из окна ZIP. Для сервера и сборки нужен Python 3; `py -3 --version` должен работать. Если доступна только команда `python`, заменить `py -3` на неё. Установку Python на новом ПК выполнить отдельно; интерпретаторы старого ПК не переносились.

В терминале в корне распакованного проекта:

```powershell
py -3 -m http.server 8765 --bind 127.0.0.1 --directory bez-korney-preview
```

Открыть http://127.0.0.1:8765/ и оставить терминал работающим. Альтернатива — двойной щелчок `start-preview.cmd`. Остановка: Ctrl+C. Если порт занят, использовать 8766 и соответствующий адрес. На телефоне 127.0.0.1 указывает на сам телефон, не на компьютер. Не раздавать весь архив через сервер: медиаоригиналы и документация не предназначены для публикации.

После правок фрагментов:

```powershell
py -3 assemble-preview.py
```

Это готовая статическая сборка для проверки. Веб-зависимости не устанавливаются. `noindex,nofollow` в предпросмотре сохранён намеренно; это не SEO-готовый продакшен. Перед публикацией требуется отдельная проверка.

Старую версию можно смотреть отдельно:

```powershell
py -3 -m http.server 8766 --bind 127.0.0.1 --directory bez-korney
```

Её страница работ локально — `/works.html`; Python-сервер не создаёт автоматически красивый маршрут `/works`.

## Необязательные инструменты анимации

Готовые GIF и SVG уже сохранены, ничего устанавливать для их использования не нужно. Для повторного рендера нужны Node.js и Pillow. На старом ПК проверка выполнялась с Node 24.22.1, Pillow 13.0.0, @napi-rs/canvas 0.1.100, sharp 0.35.5. Версии графических библиотек зафиксированы в новых манифестах; установка с чистого интернета в этой задаче не проверялась, lock-файл ранее отсутствовал.

```powershell
npm install
py -3 -m pip install -r requirements-graphics.txt
node sketches/render-approved-gif.cjs
py -3 sketches/encode-approved-gif.py
```

Кадры создаются в `sketches/approved-gif-frames`, они исключены из ZIP как воспроизводимые. Кодировщик при наличии основной GIF создаёт `-v2.gif`. После проверки результата заменять основную GIF и пересобирать страницу только по согласованию. Исторический `render-bez-brand.cjs` создаёт старую квадратную анимацию, для нового утверждённого ролика его не использовать. Шрифт IBM Plex Mono Light.ttf сохранён; HTML-эскиз также обращается к Google Fonts, поэтому его подпись офлайн может использовать запасной шрифт. Растровая GIF уже содержит нужный шрифт.

## Утверждённые решения

- Бренд БЕЗ КОРНЕЙ. Подпись строчными: «ателье искусственного озеленения». Основной логотип — полное фирменное SVG-написание; не заменять обычным текстом. Эталоны `bez-korney/bez-portal-light.svg` и `bez-portal-dark.svg`, viewBox `40 30 430 79`, сохранять пропорции.
- Architectural Editorial: воздушная редакционная композиция, чередование блоков, кремовый #f3f0e9, графит #20211d, терракота #ac3d2e. Нестандартная вёрстка, но понятные действия. Не превращать в типовой сайт озеленения.
- Первый экран: «Зелень, меняющая пространство». Пояснение: «Композиции из искусственных растений для коммерческих интерьеров». Старое «Зелень как часть архитектуры» сохранить как запасное, не возвращать автоматически. Воронеж только в контактах.
- Фокус на интерьерах. Не продвигать входные группы как главное направление, не акцентировать пиццерии, не выдумывать заказчиков и объекты. Частные дома интересны в сотрудничестве с дизайнерами.
- Кнопки по мотивам Reshape 07 / Janus: светлое асимметричное пятно, тонкий терракотовый контур, Georgia italic 400, морфинг и подъём надписи. Дополнительная магнитность и превращение в лист отклонены. Эталон `bez-reshape-brand.html`.
- Анимация `bez-roots-reveal.html`: утверждённый вектор корней по пользовательской пиктограмме, горизонтальная линия, втягивание корней в К, поворот, сборка слова, лист над Й. Подпись IBM Plex Mono Light 300, 16 px / адаптивно 12 px. Прежние самостоятельно нарисованные корни отвергнуты.
- Авторское БЕЗ сохранено в `bez-new-directions.html`, но не утверждено для основного логотипа. Компактная К и варианты мерча — история экспериментов, не замена основного знака.
- Преимущества: без привязки к окнам, без полива и досветки, предсказуемый облик. Ответ о натуральности: «Естественное впечатление складывается из деталей: оттенков зелени, фактуры листьев и плавных изгибов ветвей. Мы подбираем их сочетание с учётом света, масштаба и характера вашего интерьера».
- Работы: реальные зонирующие кашпо, фитостена у лестницы, светлое кашпо. Два нижних фото равной высоты и пропорции 4:5. Разрешённая ретушь отдельно: `wall-clean.png` (убрана сумка) и `seating-close-retouched.png` (коррекция фото). Оригиналы сохранены. Общий кадр монтажа честно подписан.
- Процесс: знакомимся с пространством → собираем решение → воплощаем на месте. Кнопка «Познакомимся?» в фирменном стиле.
- Стоимость: масштаб, растения и плотность, монтаж. Слева «У каждого пространства — свой расчёт». Пример раскрывается плюсом: 6 500 ₽ за растения и работу, БЕЗ кашпо; цена только для показанной композиции, не за м². Точный состав и размеры не известны. Отдельно «Предложим решение под ваш бюджет».

У локальных репозиториев нет remote. В основной старой папке нет ни одного коммита; в публикационной есть история, HEAD 5890567, локально изменены два site.css. ## Как продолжить в ChatGPT Work / Codex

1. На новом компьютере установить/открыть настольное приложение, войти в свой аккаунт и нужное рабочее пространство.
2. Распаковать архив и открыть папку BEZ-KORNEI как локальный проект, разрешив доступ к ней. Локальная папка должна находиться на новом ПК; история чата сама не переносит файлы.
3. Для разработки использовать доступ к локальной папке; в Codex — локальное окружение. Названия пунктов интерфейса зависят от доступного режима и версии приложения.
4. Дать первое задание: «Продолжаем БЕЗ КОРНЕЙ. Прочитай AGENTS.md и PROJECT_HANDOFF.md, затем docs/VALIDATION.md. Основная версия — bez-korney-preview. Запусти локально и проверь проблему заставки. Не публикуй, не меняй DNS и не устанавливай WordPress».
5. Если открывается новый чат, этот handoff заменяет зависимость от старой переписки. Саму историю сообщений и авторизации в ZIP не включали. Для конкретных предыдущих обсуждений при необходимости приложить выдержки из старого чата.

Официальная документация, проверенная при подготовке: https://learn.chatgpt.com/docs/quickstart?setup=app и https://learn.chatgpt.com/docs/environments/modes . Папки проекта и локальное окружение подключаются в настольном приложении; ZIP не переносит сеансы авторизации.
