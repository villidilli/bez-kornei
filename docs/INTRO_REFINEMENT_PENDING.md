## Применение после восстановления доступа

Ветка создана от GitHub main aa3019e. Рабочая Windows-копия содержит более свежие утверждённые изменения индикатора загрузки (12 листьев с боковыми прожилками и одинаковой прозрачностью). Не заменять локальный каталог целиком этой веткой. Перенести только изменения масштаба и подписи, сохранив местные изменения индикатора и отдельные эскизы.

Запустить `node scripts/install-intro-font.cjs`, затем текущий локальный `assemble-preview.py`. Проверить загрузку шрифта, кириллицу, мобильную ширину, reduced motion и вновь записать GIF из актуального рендера.
