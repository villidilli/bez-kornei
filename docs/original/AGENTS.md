## Сайт по озеленению

Пользователь с супругой оформляет коммерческие интерьеры и входные зоны искусственными растениями и цветами. Среди работ есть озеленение посадочных зон сети пиццерий. Для будущего сайта обсуждалась премиальная европейская арт-дирекция. Референсы пользователя — Build in Amsterdam, Bloom & Wolf, Bürocratik, Studio Dumbar и Mutina. Разработку сайта начинать по отдельному заданию пользователя.
