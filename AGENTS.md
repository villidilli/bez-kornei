# БЕЗ КОРНЕЙ: инструкции для продолжения

Сначала прочитать PROJECT_HANDOFF.md и docs/VALIDATION.md. Подробная исходная история решений — docs/original/AGENTS.md; там есть отменённые варианты. Последние решения в PROJECT_HANDOFF.md приоритетны.

- Основная версия — bez-korney-preview; редактировать блоки в sketches, затем assemble-preview.py. assembly.css/js редактируются отдельно.
- Сохранять Architectural Editorial и утверждённый SVG-логотип. Не выдумывать проекты, цены, адреса, условия сотрудничества.
- Личный адрес ИП не публиковать.
- Существенные изменения согласовывать. Без отдельного задания не публиковать, не менять DNS, не покупать услуги, не устанавливать WordPress.
- Заставка: пользователь сообщает, что не видит её. Дефект не закрыт; подробности в handoff.
- Пути старого ПК в docs/original и SOURCE_MAP — исторические; использовать переносимые файлы этого проекта.

- Brand layout: logo and atelier subtitle always form one lockup. In a right text column align both right; in a left text column align both left. Visual columns reach the top and bottom screen edges; place branding within the text column.
