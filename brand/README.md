## Как продолжать работу

Сначала читать корневой SOURCE_MAP.md. Не менять форму и пропорции основного логотипа. Подпись и логотип образуют единый блок.

Знак для мерча сохранён без изменения исходного изображения «Терракотовая К с листиком.png» (libfile_00f309d88f4c819184336bb3460c9b9f). Для производства нужен отдельно подготовленный вектор и требования подрядчика; favicon не считать утверждённым производственным макетом.

Старые bez-merch-k.png и bez-merch-roots.png сохранены как история; не датировать их сегодняшним днём. Оригиналы разработок остаются в sketches/. HTML-эскизы с относительными ссылками открывать из sketches/, где находятся соседние ресурсы.
