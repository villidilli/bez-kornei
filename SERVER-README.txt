БЕЗ КОРНЕЙ — локальный сервер Windows

Поместите Start-Server.exe рядом с папкой bez-korney-preview и запустите двойным щелчком.
В текущем проекте программа уже находится на нужном месте.
Сервер запускается без Node.js, Python и PowerShell-сценариев.
Браузер не открывается автоматически. Адрес показан в консоли.
Обычно это http://127.0.0.1:8765/; если порт занят, выбирается следующий до 8775.
Остановка: закройте консоль или нажмите Ctrl+C.
Сервер доступен только на этом компьютере.
PreviewServer.cs — исходник программы.
